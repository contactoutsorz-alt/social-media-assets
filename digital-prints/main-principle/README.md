# Digital Prints / Main Principle

Source: original Canva country-map print collection, 30×45 | 2:3 (Canvases (Portrait)).
Style: Cinzel Decorative Bold, uppercase below a white map silhouette on #601f01, framed in a realistic sunlit interior.

## Assets

- `shared/` contains **54 current PNG mockups** available to both Instagram and Pinterest.
- Older `_old.png` versions were deleted on 23 October 2026.
- `instagram/` and `pinterest/` are reserved for any future platform-specific assets.

## Publishing

Digital Prints uses the **separate Buffer account** and a private GitHub Actions workflow in `contactoutsorz-alt/Linkedin-autoposter` at `.github/workflows/digital-prints-autopost.yml`.

- Instagram `stateprintings`: daily **15:00** and **19:00** Europe/London.
- Pinterest `stateprintings`: daily **15:00** and **19:00** Europe/London.
- Each platform cycles through every current image independently before repeating an image.
- Buffer's small rolling queues are replenished automatically from GitHub Actions.
- Current captions describe **digital downloads** only, including 3 high-resolution JPG files at 300 dpi, with relevant wall-art hashtags.
- Product destination URLs have not been supplied for Pinterest, so none are invented.

## Outstanding artwork
